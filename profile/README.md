# ALIA Labs

**Difficult problems. Built solutions.**

ALIA Labs is a global applied engineering and technical services company. We take on requirements that do not fit neatly inside an existing product, vendor, or department: we design the solution, assemble the capabilities, prove it works, and stay accountable through delivery.

This organization holds the engineering work we release publicly. Every repository here exists because we needed it, and each one demonstrates a different discipline.

## The work

| Repository | What it proves |
|---|---|
| **Carbon** | Bit-exact deterministic training across GPU architectures. Same seed, different GPU, identical weights. |
| **Molten** | Fused CUDA kernel generation from mathematical specifications. Write the math, get the kernel, with correctness validation and reproducible benchmarks. |
| **Redline** | Compile-time performance guarantees for Rust. Code that would cross the performance line does not compile. |
| **Sealed** | Cryptographic attestation, behavioral sandboxing and trust verification for package installs across ecosystems. |
| **Foundry** | HTML, CSS and JavaScript compiled to GPU-rendered native binaries. |
| **Pane** | A GPU-aware system monitor for Windows: per-process VRAM, dual-GPU support and hardware controls in a single binary. |

Beyond open source, we build and operate our own GPU inference infrastructure, including a from-scratch CUDA C++ runtime that serves large mixture-of-experts models on consumer hardware. Measured results are published at [alialabs.org/research](https://alialabs.org/research).
